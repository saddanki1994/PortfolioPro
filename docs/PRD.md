# Product Requirements Document

## Product Name

PortfolioPro

---

## Vision

Build a professional portfolio management platform using Google Sheets and Google Apps Script.

---

## Objectives

- Single source of truth
- Automatic calculations
- Multi broker
- Multi account
- Multi currency
- Professional dashboard

---

Individual Investors

- Canada Life

## Supported Assets

- Stocks
- ETFs

## Supported Accounts

- TFSA
- RRSP
- Non Registered

---

## Supported Currencies

- CAD
- USD

---

## Success Criteria

- Portfolio value updates automatically
- Cash ledger updates automatically
- Holdings generated automatically
- Dashboard updates automatically
