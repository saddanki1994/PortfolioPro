## Overview

PortfolioPro is a professional portfolio management platform designed for investors who manage multiple brokers, multiple accounts, multiple currencies, and multiple asset classes.

Unlike a traditional spreadsheet, PortfolioPro follows software engineering principles with modular architecture, documentation, version control, and automated calculations.

The Google Sheet serves as the user interface while Google Apps Script provides the business logic.
